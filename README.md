# Personal Mini-Toolkit

## What My Toolkit Does

My Personal Mini-Toolkit is a Python program with three useful tools:
- A Simple Calculator for basic math operations.
- A To-Do List for adding, viewing, and removing tasks.
- A Number Guessing Game for guessing a secret number.

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```text
python toolkit.py
